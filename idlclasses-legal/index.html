About the TikTok integration

Private integration

The IDL Classes TikTok integration is a small, owner-operated tool. It uses TikTok's official Content Posting API to upload the channel's own educational videos to the channel's own TikTok account. It is not offered as a public app, and it does not upload content for anyone else.

What the tool does It authenticates with TikTok using OAuth, sends the video file and caption that the channel owner chooses, checks whether TikTok finished processing the post, and keeps a local receipt. It does not read followers, messages, analytics, or any other TikTok user's data.

Who runs it

IDL Classes is an independent educational channel. You can find the lessons on YouTube. The channel's main website is idlbridge.com.
